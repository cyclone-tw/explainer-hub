TinyAgent autonomy loop

核心在 agent.py：模組邊界清楚，迴圈就是 Thought → parse → Action → Observation，直到 final_answer。

  1. 01
    memory.add(user)寫入任務；可帶 image（Ch9 multimodal）。
  2. 02
    LLM.generate純 urllib 打 OpenAI-compatible /chat/completions；可掛 tools schema。
  3. 03
    parse文字 JSON 的 ReAct，或原生 tool_calls 的 NativeReAct。
  4. 04
    execute → observe結果回寫 memory；trajectory 記錄步驟；達 max_steps 或 final_answer 結束。

強項、限制、建議用法

強項

  • 圖解 + 模組化，學習曲線平緩
  • 真的從零組，不是只包框架
  • 涵蓋 MCP、native tool calling、skills、coding agent
  • Colab 免費路徑清楚

限制

  • 教材型 runtime，非 production orchestration
  • 評測／多代理章相對輕
  • execute_python 有 timeout，非完整 sandbox 敘事
  • 教學迭代痕跡（偶有重複命名）

建議：當「底層原理課」。產品多代理再接 CrewAI / AutoGen / 自家 orchestrator。讀完 newsletter → 跑 Ch1–10 → 對照自己系統的 memory / tools / planner 邊界。
